# LexiPro 本地原生离线发音伴侣服务 (Sherpa-ONNX / Kokoro-82M)

本服务是专为 **LexiPro 划词翻译扩展** 与 **油猴脚本** 打造的本地独立发音伴侣程序。

底层直接采用国际顶级开源语音团队 `k2-fsa` 研发的 **`sherpa-onnx`** 原生 C++ 动态链接库与 **`Kokoro-82M`** 离线语音模型，**与开源划词工具 NextAI Translator 采用完全一致的底层技术内核**。

---

## 为什么使用本地原生伴侣服务？

| 痛点 / 体验 | 浏览器内跑 WebGPU/WASM | **本地原生伴侣服务 (本方案)** |
| :--- | :--- | :--- |
| **Chrome 内存占用** | 膨胀 500MB ~ 1GB | **0 MB**（浏览器只负责通过标准 `<audio>` 播放音频） |
| **系统流畅度** | 频繁跨显存/内存搬运张量，可能造成系统渲染掉帧卡顿 | **0% 掉帧**，完全不占显卡，系统极度丝滑 |
| **发音延迟** | 首次需加载几百兆上下文至浏览器 | **30ms ~ 100ms** 毫秒级极速响应 |
| **环境兼容** | 依赖浏览器 WebGPU/WASM 兼容性 | 纯原生 CPU AVX2 指令集，开箱即用 |

## 快速使用

1. **一键启动**：
   直接在项目根目录双击 **`start-local-tts.bat`**。
   * 首次启动会自动拉取原生依赖并自动下载 Kokoro 英文离线模型（约 305 MB）；
   * 服务启动后默认监听在 `http://127.0.0.1:18080`。

2. **在浏览器扩展 / 油猴设置中启用**：
   * 打开扩展设置中心，将【语音发音引擎配置】切换为：
     **`🚀 本地原生伴侣服务 (Sherpa-ONNX / Kokoro 原生 C++ · 毫秒响应 · 零浏览器内存)`**
   * 点击【🔍 测试连接】确认显示绿色 `● 本地原生引擎已就绪` 即可！

## HTTP API 说明

* **健康检查**：
  * `GET http://127.0.0.1:18080/health`
* **发音接口**：
  * `GET http://127.0.0.1:18080/tts?text=apple&voice=af_heart&speed=1.0`
  * 返回标准二进制 `audio/wav` 流，直接通过浏览器播放。
* **OpenAI 兼容接口**：
  * `POST http://127.0.0.1:18080/v1/audio/speech`
  * Body: `{"input": "Hello world", "voice": "af_heart"}`
