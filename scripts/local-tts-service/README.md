# LexiPro 本地原生离线发音伴侣服务 (Sherpa-ONNX / Kokoro-82M + MeloTTS 双引擎)

本服务是专为 **LexiPro 划词翻译扩展** 与 **油猴脚本** 打造的本地独立发音伴侣程序。

底层直接采用国际顶级开源语音团队 `k2-fsa` 研发的 **`sherpa-onnx`** 原生 C++ 动态链接库，**与开源划词翻译工具 NextAI Translator 采用完全一致的底层技术架构**。

---

## 双引擎智能架构

* 🎙️ **英文引擎**：**`Kokoro-82M`**（11 种自然男女声，拟真度断层领先）
* 🇨🇳 **中文/混读引擎**：**`MeloTTS`**（MyShell 研发开源，专攻自然汉字连续变调与 44.1kHz 高保真混合朗读）
* 🔀 **智能语种分流**：
  * 当朗读文本包含汉字时，系统毫秒级自动切换至 **MeloTTS**；
  * 当朗读文本为纯英文时，系统自动切换至 **Kokoro-82M**；
  * 也支持强制指定 `model=kokoro` 或 `model=melo`。

---

## 为什么使用本地原生伴侣服务？

| 痛点 / 体验 | 浏览器内跑 WebGPU/WASM | **本地原生伴侣服务 (本方案)** |
| :--- | :--- | :--- |
| **Chrome 显存/内存占用** | 膨胀 500MB ~ 1GB，抢占 GPU 显存 | **0 MB**（浏览器只负责通过标准 `<audio>` 播放音频） |
| **系统流畅度** | 频繁跨显存/内存搬运张量，可能造成系统渲染掉帧卡顿 | **0% 掉帧**，纯 CPU AVX2 指令集推理，系统极度丝滑 |
| **发音延迟** | 首次需加载几百兆上下文至浏览器 | **30ms ~ 100ms** 毫秒级极速响应 |
| **运行形态** | 需保持扩展页面或黑窗口 | **支持完全静默后台无窗口运行 / 开机自启** |

## 启动与使用指南

### 1. 启动方式（二选一）

* **方式 A：一键后台静默运行（推荐，完全无黑窗口）**：
  * 在项目根目录双击 **`一键后台静默启动.vbs`**（或 `start-silent.vbs`）。
  * 窗口完全隐藏，在后台静默常驻，不占用任务栏和前台任何空间。
* **方式 B：开机自动静默启动（一次配置，永久省心）**：
  * 在项目根目录双击 **`开机自动静默启动.bat`**。
  * 脚本将自动在 Windows 启动项生成静默捷径，之后每次开机自动常驻后台。
* **方式 C：控制台调试运行**：
  * 双击 **`start-local-tts.bat`**，可在控制台实时查看发音日志。

### 2. 停止服务

* 需要关闭服务时，双击根目录下的 **`停止后台服务.bat`** 即可一键安全终止后台进程。

### 3. 在扩展设置中启用

1. 打开扩展设置中心，将【语音发音引擎配置】选为：
   **`🚀 本地原生伴侣服务 (Sherpa-ONNX: Kokoro 英文 + MeloTTS 中文双引擎 · 零浏览器内存 · 支持静默常驻 · 推荐)`**
2. 点击【🔍 检测连接】，确认显示绿色 `✅ 服务在线 (Kokoro英文 + MeloTTS中文双引擎就绪 · 零浏览器内存)`；
3. 点击【🔊 试听英文 (Kokoro)】或【🔊 试听中文 (MeloTTS)】验证；
4. 点击【💾 保存全部配置】即可！

## HTTP API 说明

* **健康检查**：
  * `GET http://127.0.0.1:18080/health`
* **发音接口**：
  * `GET http://127.0.0.1:18080/tts?text=apple&voice=af_heart&speed=1.0`
  * `GET http://127.0.0.1:18080/tts?text=你好世界&speed=1.0`
  * 返回标准二进制 `audio/wav` 流，直接通过浏览器播放。
* **OpenAI 兼容接口**：
  * `POST http://127.0.0.1:18080/v1/audio/speech`
  * Body: `{"input": "Hello world", "voice": "af_heart"}`
