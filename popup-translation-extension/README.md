# Popup Translation - AI 划词翻译与生词高亮 (Chrome 扩展版)

> 🌟 **系统性移植与升级的 Chrome 扩展程序 (Manifest V3 标准)**  
> 融合全网 AI 划词翻译、动森原生 UI、Notion 知识库增量同步与页面生词高亮；  
> 并深度适配 **Reddit 帖子/评论** 与 **路透社 (Reuters) 新闻** 一键双语全文翻译！

---

## 🚀 核心功能体系

### 1. 全网 AI 划词翻译与动森字典弹窗
- **点击泡泡破裂动效**：在任意网页选中英文文本，选区右上角优雅出现动森经典小圆点，点击破裂并展开弹窗；
- **Shadow DOM 物理隔离**：弹窗与宿主网页 CSS 100% 隔离，绝无排版冲突与样式污染；
- **大模型专业释义**：硅基流动 Qwen 高速模型矩阵驱动，精简输出音标、词性、精准释义与双语例句（已彻底剔除多余同反义词）；
- **动森打字机逐字显示 (Typewriter)**：平滑逐字呈现，保留富文本排版；
- **真人发音与字号调节**：支持有道真人音频朗读，提供独立的 `Aa` 胶囊字号微调面板。

### 2. Notion 生词本增量同步 (SWR) 与页面生词高亮
- **SWR 高速算法**：本地毫秒级直出，后台异步增量拉取 Notion 最新词库；
- **Island 不规则气泡高亮**：浏览任意英文网页时，自动高亮生词本中的单词，鼠标悬停即查词；
- **一键收藏同步**：弹窗中点击 ★ 即可将新单词实时同步写入 Notion Database。

### 3. 三种专属呈现样式（自由切换）
- **沉浸直接替换（默认推荐）**：直接沿用 Reddit 帖子和评论原有的 HTML 标签、字号、字体与行高排版，仅将其中的英文替换为中文，视觉上天衣无缝；
- **下划线双语对照**：上面显示英文原文，下方紧跟带有优雅虚线下划线的中文译文，字体字号直接继承原文，无多余边框遮挡；
- **独立轻量卡片**：在原文下方内嵌柔和微卡片，提供微型复制与折叠按钮。
- **即时热切换**：无论在选项设置中心还是在页面右下角悬浮胶囊展开菜单中，均可一键即时热切换这 3 种样式！

### 4. Reddit & 路透社 (Reuters) 专属全文翻译增强
- **进站自动翻译开关**：在设置中心、悬浮胶囊菜单或右上角弹窗中可一键开启「进入页面自动翻译」，打开 Reddit 帖子或路透社新闻时无需手动点击，自动完成整页翻译；深度适配 Reddit SPA 单页无刷新路由跳转；
- 访问 [Reddit](https://www.reddit.com/) 或 [路透社 (Reuters)](https://www.reuters.com/) 时自动在右下角唤出**现代磨砂黑微光悬浮胶囊**（支持自由拖拽与吸附记忆）；
- 一键并发批量翻译帖子标题、正文以及各级嵌套评论/新闻段落；
- 动态向下滚动监听，发现新评论时自动显示徽章（如 `+12`）并支持增量翻译。

## 📥 如何在浏览器中安装导入

无需任何编译或命令行打包，解压即用：

### 第一步：打开扩展管理页面
在 Chrome 或 Edge 浏览器地址栏输入：
```text
chrome://extensions/
```
*(Edge 浏览器可输入 `edge://extensions/`)*

### 第二步：开启开发者模式
在扩展管理页面的**右上角**，打开 **「开发者模式」(Developer mode)** 开关。

### 第三步：加载已解压的扩展程序
1. 点击左上角出现的 **「加载已解压的扩展程序」(Load unpacked)** 按钮；
2. 在弹出的文件选择器中，选中当前目录下的文件夹：
   ```text
   <你的本地仓库目录>\popup-translation-extension
   ```
3. 点击「选择文件夹」即可导入成功！

## ⚙️ 快捷配置与说明

- 开源公开版不再内置任何 API Key，安装后请先在扩展设置（AI 翻译引擎）中填入你自己的硅基流动 API Key（推荐 `Qwen/Qwen2.5-7B-Instruct`）或 Kimi Token；
- 点击浏览器右上角扩展图标可查看当前网站适配状态，点击齿轮 ⚙️ 可进入设置页面配置专属 API Key 或 Notion Token；
- 所有的网络请求均通过 Background Service Worker 代理，彻底规避任何页面的 CSP 内容安全策略限制。
